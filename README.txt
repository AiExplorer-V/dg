DudeGifts — Responsive Multi-page Website

This version includes a client-side shopping cart with no login required.

Cart behavior:
- Add products from Physical Gifts, Digital Gifts, and Surprise Events.
- Cart is saved in browser localStorage.
- Increase/decrease quantities or remove products.
- Cart badge appears in the navigation.
- Review all selected products and total.
- Confirm the full order through WhatsApp.
- No account/login is required.
- Existing product galleries, filters, popups, navigation and responsive layouts are preserved.

Deploy all files together on any static hosting service.
