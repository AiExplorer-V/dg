DUDEGIFTS — MEMORY ATELIER

A premium gifting storefront built around emotional discovery, editorial storytelling, personalization and a gift-box cart.

Run:
- Open index.html directly, or host the folder on GitHub Pages / Netlify / Vercel.

Before production:
1. Replace sample Unsplash image URLs with DudeGifts-owned product/campaign photography.
2. Replace 919999999999 in app.js and contact.html with the real WhatsApp Business number.
3. Replace sample testimonials with verified customer reviews.
4. Connect a real backend/payment/order system for production orders.
5. Configure your own fonts locally if you want the site to work without Google Fonts.

Main pages:
index.html, gifts.html, product.html, digital-gifts.html, surprise-events.html, custom-gift.html, about.html, contact.html, cart.html
