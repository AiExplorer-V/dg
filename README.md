# DudeGifts — Memory Atelier v2

A premium gifting storefront built around emotion, personalization and editorial storytelling.

## v2 updates
- Completely redesigned hero composition: no longer a generic split-screen/stock-photo hero.
- Desktop hero uses an editorial three-image collage with layered storytelling.
- Mobile hero has a dedicated compact composition, readable typography, stacked CTAs and controlled image height.
- Added a social studio strip and social icons to the bottom of every page: Instagram, Facebook, WhatsApp and YouTube.
- Social URLs are centralized in the footer markup so they are easy to replace with the brand's verified handles/number.
- Preserved multi-product cart, no-login flow, personalization UI and WhatsApp ordering.
